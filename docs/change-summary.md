# 改动、验证与恢复

## 原始状态与保留

项目最初只有《考核规则.md》《项目要求.md》，无可执行程序、无 Git 仓库，因此不存在可对比的原版程序行为。两份输入已计算 SHA256，见 `source-sha256.json`，最终验证确认未修改。原始文档另以本地提交 `459863f` 保存。

## 新增产物

新增 Python 标准库 CLI、单Agent有界循环、真实模型适配器、显式Mock、检索/原文读取工具、三套合成语料、十项验收矩阵、自动测试、实际运行和文档。没有修改外部应用或系统配置；用户模型密钥仅保存在本地忽略文件 `.env`。

## 真实行为差异

第一轮 live-v1 自动检查8/10；资料外问题和新增冲突因连续格式不合规耗尽预算。第二轮增加完整结束动作格式示例、结构化格式错误反馈、剩余预算提示和无资料检索停止指导，不放宽验收条件；live-v2固定10项全部通过。

另修复空白引用可被当成证据、无关成功搜索清除读取失败、数字子串误判、无效用例结构异常；对应回归测试保留。移除验收整句检索映射，保留通用词归一化。未证明这些变化能带来统计意义的泛化提升。

## 查看差异与恢复方法

```bash
# 查看从最初两份要求到当前实现的全部改动
git diff 459863f HEAD --stat
git diff 459863f HEAD -- src tests data docs README.md

# 只恢复原始要求文件；当前两文件已保持不变，通常不需要执行
git restore --source=459863f -- 考核规则.md 项目要求.md

# 查看任一提交，不覆盖当前工作区
# 在另一个空目录建立只读审查用途的工作树
git worktree add --detach ../knowledge-agent-baseline 459863f
```

不建议 `reset --hard` 或 `git clean`，避免删除用户本地配置及复跑记录。`.env` 是未跟踪的本地文件，恢复 Git 提交不会恢复或删除它。提交前已在额外临时工作树核验基线文件哈希，最终实现和运行记录保留在本目录。
